# 合同会社LosToros コーポレートサイト制作ブリーフ

最終更新: 2026-07-06

## 会社の特徴

- 合同会社LosToros
- **陸上競技のプロチーム**という側面を持つ会社（サイトデザインの軸）
- 詳細な会社情報（概要・メンバー・スポンサー・事業内容）はクライアントから受領待ち

## 決定事項

### サイト構成: シングルページ構成

セクション順序（上から）:

1. ヒーロー（トップ） — 動きのある演出。陸上チームらしい「スピード・躍動」をモチーフ
2. About / 会社概要 — 社名・代表・所在地・設立など
3. 事業内容 / サービス
4. メンバー紹介 — 選手・スタッフのプロフィール
5. スポンサー紹介 — スポンサーロゴ掲載欄（クライアント要望）
6. お問い合わせ

### デザイン方針: テック・先進的（動きあり）

- ダーク基調やグラデーション、スクロール連動アニメーション、3D表現も検討
- 「スポーツチームの熱量 × テックの洗練」の掛け合わせ
- AIっぽい平均的なデザインを避ける。参考サイトの分解に基づく独自デザイン

### 制作フロー: 「参照 → 分解 → 実装」

1. **参照**: 参考サイトのURLを取得・解析（WebFetch / Playwrightスクリーンショット）
2. **分解**: 配色・タイポグラフィ・レイアウト・余白・アニメーション手法を
   「デザイン分解メモ」として文書化（docs/ に保存）
3. **実装**: HTML/CSS/JS（必要ならThree.js）を直接記述。
   内蔵Chromiumでスクリーンショット確認しながら仕上げる
4. このフローは `.claude/skills/` にSkillとして固定化する（再利用可能に）

注意: 参考サイトは技法の参照のみ。デザインの複製はしない（著作権）。

3. 事業内容

## 環境メモ

- セッション環境のネットワークアクセスが Trusted（制限あり）だと外部サイトの
  取得・スクリーンショットが403でブロックされる。Full access への変更を依頼中
- Playwright利用時は内蔵Chromium（/opt/pw-browsers/chromium）を
  executablePath に指定する（playwright install は不要）
