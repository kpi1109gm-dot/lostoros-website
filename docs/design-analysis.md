# デザイン分解メモ: freegamemgmt.com → LosToros への翻訳

参照日: 2026-07-06 / 参照URL: https://www.freegamemgmt.com/
（クライアント指定の参考サイト。「シンプルでスタイリッシュ」の基準）

## 1. 参照サイトの分解

### 技術スタック

- Webflow製 + jQuery + **GSAP 3.12.5 + ScrollTrigger**（スクロール連動アニメーション）
- ページ全高 約7,300px のシングルページ + 下層ページ（Manifesto等）

### タイポグラフィ（このサイトの個性の8割）

| 役割 | フォント | 特徴 |
|---|---|---|
| 見出し・巨大ロゴ | Druk Text (900) | 超極太コンデンス、全て大文字、画面幅いっぱいに敷く |
| 本文・ラベル | PP Supply Mono | 等幅（タイプライター風）、大文字、小さめ16px |

- H1がビューポート幅いっぱいの「FREEGAME」ワードマーク（ヒーローとフッターで反復）
- 本文まで等幅フォント大文字 → 「ドキュメント/帳票」のような編集的トーン

### 配色

- **白 #FFF / 黒 #000 の2色が基本**。テキストは白(on黒)・黒(on白)のみ
- アクセントは **ゴールド rgb(204,159,83)** をボタン1箇所だけに使用
- 写真・動画は全てモノクロ処理 → 色数を徹底的に絞ることで「高級感・編集感」

### レイアウト構造

1. ヒーロー: モノクロ動画背景 + 画面幅いっぱいのワードマーク + 小さな筆記体アクセント
2. ステートメント: 番号付き見出し（001〜005）+ 罫線区切りの編集的リスト
3. コラージュ: ポラロイド風写真を散らし、手描きの走り書き線・丸囲みを重ねる
4. 白→黒の切り替えに「破れ紙」エッジ、方眼紙テクスチャ
5. ニュースレター登録（ゴールドのボタン）
6. フッターで再び巨大ワードマーク

### モーション

- スクロール連動の出現アニメーション（GSAP ScrollTrigger）
- 画像のパララックス、マーキー（流れるテキスト）
- ホバーで下線が引かれるナビ
- 3D的な要素は「サイン入りボール」の動画素材で表現（実装は動画）

### なぜ「シンプルでスタイリッシュ」に見えるか（本質）

1. 色数を2+1色に制限、写真をモノクロ統一
2. フォントを2種類に制限し、サイズの振れ幅を極端に（16px ↔ 20vw）
3. 余白と罫線で整理された「編集デザイン」の骨格
4. 手描き要素・紙テクスチャで「人間味」を1割だけ混ぜる

## 2. LosToros への翻訳方針

丸コピーはしない。上の「本質」を保ちつつ、闘牛×スプリントの独自要素に置換する。

| 参照サイトの要素 | LosToros版 |
|---|---|
| Druk の巨大ワードマーク | **Goldman**（クライアント指定・ロゴタイプのベース）で「LOSTOROS」 |
| PP Supply Mono の英語ラベル | Google Fonts の **Space Mono**。日本語本文は **Noto Sans JP** |
| ゴールド1点アクセント | **闘牛の赤（マタドールレッド #C8102E 系）** 1点アクセント |
| モノクロ写真 | 写真未提供のため当面はタイポ+グラフィック表現。撮影後にモノクロ写真を配置 |
| 001〜005 の番号付きリスト | CONCEPT / VISION / MISSION と事業内容で同形式を採用 |
| 破れ紙エッジ | **斜めのスラッシュ（スピード線/トラックのレーン）**で白黒を切り替え |
| 筆記体の走り書き | 赤の手描き風丸囲み・下線（SVG）を1〜2箇所だけ |
| マーキー | 「EL TORO BRAVO / LOSTOROS TRACK TEAM」の流れるテキスト |
| GSAP ScrollTrigger | 依存を減らすため vanilla JS（IntersectionObserver + rAF）で同等の動きを実装 |

### ページ構成（シングルページ・決定済み構成に対応）

1. ヒーロー — 黒。巨大「LOSTOROS」+ コンセプトコピー + トラックレーンのグラフィック
2. マーキー（赤）
3. ABOUT — 白。会社概要 + LosToros=闘牛の由来
4. PHILOSOPHY — 黒。001 CONCEPT / 002 VISION / 003 MISSION
5. BUSINESS — 白。事業内容4項目（番号付きリスト）+ 独自性ステートメント
6. MEMBERS — 黒。CEO千田杜真寿(100m/200m)・COO池田海(110mH)
7. SPONSORS — 白。スポンサーロゴ枠 + パートナー募集CTA（赤アクセント）
8. CONTACT + フッター — 黒。巨大ワードマーク反復

### 保留事項（素材待ち）

- ロゴマーク: 後日提供 → ヘッダー・フッター・faviconに差し込み
- 文字ロゴ: Goldmanベースで作成予定 → 本サイトのワードマークがそのまま叩き台になる
- 写真: 未撮影 → プレースホルダー箇所をコメントで明示しておく
