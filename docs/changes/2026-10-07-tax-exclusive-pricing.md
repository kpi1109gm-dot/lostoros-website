# 価格表記を税別へ統一

日付: 2026-10-07 / 実装: Claude Code / 依頼者: 池田海

## 経緯

池田さんから「税込50,000円になってしまっているので、50,000円＋税という形にしてほしい」
との依頼。着手前にSquareの決済ページを実際に開いて確認したところ、
**Square側はすでに税別表記・請求額¥55,000へ変更済み**だった。

つまりサイトだけが「税込50,000円」のままで、**実際の請求額より5,000円安く見えている**
状態だった。サイトをSquareに合わせる形で修正した。

## 方針

- **主表記は「年額 50,000 円（税別）」**（依頼のとおり）
- **決済直前と価格ブロックには「税込 55,000 円」を併記**する。
  Squareの決済ページには¥55,000と出るため、併記しないと金額が増えたように見える
- 幅の狭い固定CTAのみ「年額50,000円＋税」と短く表記

### OGP画像の差し替え方法

元の合成データが無いため、既存のJPEGのバッジ部分だけを描き直した。

1. ブランド赤 `#c8102e` の画素を探してバッジ範囲を特定（x64..419 / y486..549）
2. その矩形を `#c8102e` で塗り直す
3. Noto Sans JP Bold 29pt でテキストを再描画。
   元のインク範囲（x87..378 / y502..533）に合わせる
4. `quality=92, subsampling=0` で保存（赤と白の境界が滲まないよう4:4:4）

フォントは Google Fonts API を古いUser-Agentで叩き、`&text=` で必要な字だけ取得した
（引き継ぎ書「この作業環境の癖」の手順）。
