# 2026-10-23 サイトを複数ページ構成に分割

- **作業者**: Claude Code
- **依頼者**: 池田さん（COO）
- **きっかけ**: 「今は一ページで下にスクロールしていく形ですが、文字が多いのと内容が増えてきたことで見づらさが出ています」

## 決めたこと（池田さん承認済み）

1. 7ページ構成（トップ / about / business / members / partner / supporter / contact）
2. お問い合わせは **案A**：専用ページ `/contact/` を作り、各ページの末尾に「お問い合わせはこちら」ボタンを置く
3. 第1段階は**文面を変えずに移すだけ**。公開前にPC・スマホの画面を見せて承認をもらう
   （作業は公開されないブランチ `claude/lostoros-corporate-site-dzn7az-0due7z` で行い、承認後に公開ブランチへ反映）

## 変えたもの

| ファイル | 内容 |
|---|---|
| `index.html` | 入口ページに作り直し。ABOUT〜CONTACTフォームを各ページへ移し、代わりに EXPLORE（4ページへの入口カード）を置いた。PARTNERSのロゴ・FOUNDING PARTNERはトップにも残した。旧URL（`/#business` 等）を新ページへ転送するスクリプトを `<head>` に追加 |
| `about/` `business/` `members/` `partner/` `contact/` | 新規。元のトップから該当セクションをそのまま移した。各ページ固有の title・description・canonical・OGP・構造化データ（WebPage＋パンくず） |
| `supporter/` `privacy/` | メニュー・フッターを新構成に合わせ、お問い合わせのリンク先を `/contact/` に |
| `css/style.css` | 末尾に「複数ページ構成（2026-10-23）」ブロック。現在のページのメニュー下線、入口カード、ページ末尾の帯 |
| `js/main.js` | `/contact/?type=種別` を読んでお問い合わせ種別を選ぶ処理。固定CTAの非表示条件に `.page-end` を追加 |
| `sitemap.xml` | 新しい5ページを追加 |

## 確認したこと（公開前・ローカル）

- 元のトップの文章303か所を機械照合し、**どのページからも欠落なし**
- 8ページ × 幅390px / 1440px で横はみ出し・JSエラーなし。各ページの h1 は1つ
- トップの長さ：スマホ 16,120px → 6,133px、PC 15,014px → 5,803px
- 旧URL（`/#about` など7種）が新ページへ転送される
- 5事業の「相談する」ボタンから `/contact/` に移ると、種別が正しく選ばれる
- 内部リンク・ページ内リンクの行き先がすべて存在する。構造化データ（JSON-LD）がすべて正しく読める
- 実際のフォーム送信・Square決済は未実施（どちらも処理内容は変更していない）

## 公開後にやること

- Search Console で `sitemap.xml` を再送信（池田さん作業）
- 新しいページが検索に出るまで数日〜数週間かかる。トップのみが出ている間も問題ない
