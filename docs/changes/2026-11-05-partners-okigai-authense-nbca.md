## Authense ブランドガイドライン（2021 Version 1）への対応

| ガイドラインの項目 | 対応 |
|---|---|
| Main Color：Authense Blue `#143377` / Authense Gold `#C1A581` | 受領SVGは `#16336f` / `#bda17f`（印刷用CMYKからの変換値と思われる）だったため、Web用の指定HEX値に置き換えた。文字「司法書士法人」の黒はそのまま |
| Logo Isolation：ロゴの周囲に「X」（「t」の幅）の余白 | SVGの描画範囲の上下左右に X（17.78）の余白を持たせた。元データは下だけ不足していたので広げた。どの画面幅でも他のロゴや枠と X 以上離れる |
| Misuse：縦横比の変更・回転・文字間の変更・色の変更・低コントラストの背景・影・アイコンとの組み合わせを禁止 | 縦横比を保ったまま縮小のみ。白（#fff）の帯に置き、影・フィルターなし。アイコンとは組み合わせない |
| Misuse：色の変更 | 従来、ロゴのリンクは触れると半透明（opacity .72）になり、青や金が薄く見えていた。これを避けるため、全社共通で「3px浮かせる」効果に変更（動きを減らす設定の端末では動かない） |

ガイドラインに最小サイズの規定はない。表示幅はPC 300px、スマホ390px幅で140px、320px幅で105px。

## 追記：NBCA（一般社団法人 日本ビジネスコンディショニング協会）を追加（同日）

池田さんの依頼で5社目として OUR PARTNERS に追加（同格）。

- ロゴは**横長版**（「NBCA」＋協会名＋CONDITIONING for LIFE PERFORMANCE）を使う。
  エンブレム（盾形）版も受領したが、池田さんの指定で横長版にした
- `assets/partner-nbca.png`（478×172）：受領画像はスクリーンショットだったため、外周の枠を切り落とし、
  地の白っぽい部分を純白（#fff）にそろえた。ロゴの色・形は変更していない
- **画像の解像度が低い（元画像532×212）**。池田さんがダウンロードした高解像度版が見つかったが、
  チャットに貼られた画像はファイルとして作業環境に届かなかったため、ひとまず低解像度版で掲載。
  高解像度版をファイルで受け取ったら同じファイル名で差し替える（width/height属性も合わせる）
- 公式サイトのURLが検索で見つからなかったため**リンクなし**。分かったら `rel="sponsored noopener"` 付きのリンクにする

5社になったため、並び方を調整した（css/style.css）:

| 画面幅 | 並び |
|---|---|
| 1100px超 | 1列に5社（ロゴは高さ最大132px・幅最大200px、間隔は画面幅の3%） |
| 601〜1100px | 1列に5社（高さ最大104px・幅最大170px・間隔24px）。800px前後以下では2段に折り返す |
| 600px以下 | 2列。社数が奇数のときは最後の1社を中央に置く |

既存ロゴも少し小さくなった（高さ150px → 132px）。1440 / 1280 / 1024 / 768 / 390 / 320px で表示を確認。
