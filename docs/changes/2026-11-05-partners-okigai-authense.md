## 内容

池田さんから2社のロゴ（OKIGAIの画像、Authense司法書士法人のSVG＋ブランドガイドラインPDF）を受領し、

| ファイル | 変更 |

## Authense ブランドガイドライン（2021 Version 1）への対応

| ガイドラインの項目 | 対応 |
|---|---|
| Main Color：Authense Blue `#143377` / Authense Gold `#C1A581` | 受領SVGは `#16336f` / `#bda17f`（印刷用CMYKからの変換値と思われる）だったため、Web用の指定HEX値に置き換えた。文字「司法書士法人」の黒はそのまま |
| Logo Isolation：ロゴの周囲に「X」（「t」の幅）の余白 | SVGの描画範囲の上下左右に X（17.78）の余白を持たせた。元データは下だけ不足していたので広げた。どの画面幅でも他のロゴや枠と X 以上離れる |
| Misuse：縦横比の変更・回転・文字間の変更・色の変更・低コントラストの背景・影・アイコンとの組み合わせを禁止 | 縦横比を保ったまま縮小のみ。白（#fff）の帯に置き、影・フィルターなし。アイコンとは組み合わせない |
| Misuse：色の変更 | 従来、ロゴのリンクは触れると半透明（opacity .72）になり、青や金が薄く見えていた。これを避けるため、全社共通で「3px浮かせる」効果に変更（動きを減らす設定の端末では動かない） |

ガイドラインに最小サイズの規定はない。表示幅はPC 300px、スマホ390px幅で140px、320px幅で105px。

## 検証

トップ・`/partner/`・`/supporter/` を 1440px / 390px / 320px で表示。
4社の画像がすべて読み込まれること、横スクロールが出ないこと、PCでは1列に4社、スマホでは2列×2段になることを確認。
