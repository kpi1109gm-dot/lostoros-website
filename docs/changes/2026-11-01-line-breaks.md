# 2026-11-01 スマホで1〜2文字だけ改行される問題を修正

- **作業者**: Claude Code
- **依頼者**: 池田さん（COO）
- **きっかけ**: スマホで「チームのこれからをつく／る。」「〜取材 — ／お気軽に…」のように、
  1〜2文字だけが次の行に落ちている（PCでは起きていない）

## 原因

日本語は単語の間に空白がないため、ブラウザは**どの文字の間でも**改行できる。
画面幅が狭いスマホでは、行末にちょうど1〜2文字だけ入りきらないことがよく起きる。

## 対応

1. **HTMLの日本語に、文節ごとの改行目印 `<wbr>` を入れた**（全8ページ・約940か所）
   - 文節の判定は Google の BudouX（`tools/wbr.cjs`）。サイト表示時には何も読み込まない
   - `<br class="pc">`（PCだけの改行）の直後にも `<wbr>` を入れる。スマホではこの改行が消えるため
2. **CSS（`css/style.css` 末尾）**
   - `body { word-break: keep-all; overflow-wrap: break-word; }` … 文節の途中では改行しない
     （収まらない長い文節だけは折る。`anywhere` にすると表やカードの列幅が縮んで英単語が割れたため不採用）
   - `text-wrap: pretty`（本文）/ `balance`（見出し）… 対応ブラウザでは最後の行が短くなりすぎない
   - 幅340px以下で英語の大見出し（FOUNDERS・BUSINESS SUPPORTER）とプライバシーポリシーの見出しを少し小さく
     （以前から幅320pxで枠からはみ出していた）
   - 見出し右側の小さいラベル（「支援していただく選手」など）は折り返さない

## 確認したこと

- 全8ページ × 幅 320/360/375/390/393/402/414/430/440px で「最後の行が1〜2文字」の箇所を自動検出
  - 修正前 **70か所** → 修正後 **1か所**（幅320pxの「支援していただく／選手」のみ）
- 全8ページ × 幅 320〜1440px（12段階）で、文節の途中で割れている箇所を自動検出
  - 残りは「CSR／CSV」の「／」の前で改行される1か所のみ（読みやすさに問題なし）
- 横はみ出しなし（320 / 360 / 390 / 430 / 768 / 1024 / 1440px）
- `<wbr>` は文字を増やさないため、文章の中身・検索・構造化データには影響しない

## 今後の注意

- **文章を書き換えたら `npm install --no-save budoux && node tools/wbr.cjs` を実行する**
  （何度実行しても結果は同じ。既存の `<wbr>` をいったん外してから入れ直す）
- 実行し忘れても表示は壊れない。その文章だけ、以前と同じ普通の折り返しになる
- 検証は Chromium で実施。iPhone（Safari）の実機では未確認なので、池田さんのスマホで確認してもらう
